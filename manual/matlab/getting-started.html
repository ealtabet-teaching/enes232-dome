Getting Started with the Dome Toolbox

The Dome toolbox computes thermodynamic properties in MATLAB on the reference states of the Moran and Shapiro tables, from the same equations of state as the Dome app, and gives the same values: differences between states, and the cycle results built from them, agree closely with the tables, while a single value can differ from the printed table by about 1 kJ/kg (up to about 5 kJ/kg in parts of the superheated tables); answers graded in ENES232 use the printed tables. Each section below holds code and the output it gives. The Run button in the Live Editor runs the guide again, and dome.gettingStarted opens it.

Installing the toolbox

Open Dome.mltbx in MATLAB: double-click it, or drag it into the Command Window. MATLAB installs the toolbox as an add-on, puts its functions on the path, and keeps it installed in later sessions. help dome lists the functions, and dome.version prints the version installed.
help dome

A state from two properties

dome.state takes the fluid and two properties, each as a name and a value. A unit may follow a value. A value without a unit is read in the session's unit system, SI by default: kPa, K, m³/kg, kJ/kg and kJ/(kg·K). The state below is water at 15 bar and 280 °C.
st = dome.state('water', 'p', 15, 'bar', 'T', 280, 'C')
st =
water, superheated p = 1500 kPa 15 bar T = 553.15 K 280 °C v = 0.16276 m³/kg u = 2749.2 kJ/kg h = 2993.4 kJ/kg s = 6.8402 kJ/(kg·K) x = – cp = 2.2667 kJ/(kg·K) cv = 1.6675 kJ/(kg·K)

Saturation and two-phase states

dome.Tsat returns the saturation temperature at a pressure (in K), and dome.psat the saturation pressure at a temperature (in kPa).
T_sat = dome.Tsat('water', 'p', 3, 'bar')
T_sat = 406.6724
p_sat = dome.psat('water', 'T', 120, 'C')
p_sat = 198.6744
Inside the vapor dome, p and T are not independent, so a pair of p and T on the saturation line is refused. A two-phase state is fixed by p or T and the quality x: x = 0 is saturated liquid and x = 1 is saturated vapor.
mix = dome.state('water', 'p', 3, 'bar', 'x', 0.9)
mix =
water, two-phase p = 300 kPa 3 bar T = 406.67 K 133.52 °C v = 0.54529 m³/kg u = 2345 kJ/kg h = 2508.6 kJ/kg s = 6.4598 kJ/(kg·K) x = 0.9 cp = – cv = –
The mixture's properties follow from those of the saturated liquid and the saturated vapor at the same pressure:
liq = dome.state('water', 'p', 3, 'bar', 'x', 0);
vap = dome.state('water', 'p', 3, 'bar', 'x', 1);
h_mix = liq.h + 0.9 * (vap.h - liq.h)
h_mix = 2.5086e+03
An array of pressures gives an array of saturation temperatures. Here they trace the saturation curve of water from 0.01 bar to the critical pressure.
p_bar = logspace(-2, log10(220), 80);
T_line = dome.Tsat('water', 'p', p_bar, 'bar');
figure
semilogy(T_line - 273.15, p_bar, 'LineWidth', 1.5)
xlabel('T [°C]'), ylabel('p [bar]'), title('Saturation curve of water'), grid on

Property functions

dome.p, dome.T, dome.v, dome.u, dome.h, dome.s, dome.x, dome.cp, dome.cv and dome.rho take the same inputs as dome.state and return one property.
s_one = dome.s('water', 'p', 15, 'bar', 'T', 280, 'C')
s_one = 6.8402
An array in place of a value gives an array of results, so a parameter study needs no loop. The specific enthalpy of water at 15 bar from 250 °C to 450 °C:
T_C = 250:50:450;
h_line = dome.h('water', 'p', 15, 'bar', 'T', T_C, 'C')

A Rankine cycle

An ideal Rankine cycle with water. Superheated vapor enters the turbine at 70 bar and 460 °C (state 1) and expands isentropically to the condenser pressure of 0.2 bar (state 2). Saturated liquid leaves the condenser (state 3), and the pump returns it isentropically to 70 bar (state 4).
s1 = dome.state('water', 'p', 70, 'bar', 'T', 460, 'C');
s2 = dome.state('water', 'p', 0.2, 'bar', 's', s1.s);
s3 = dome.state('water', 'p', 0.2, 'bar', 'x', 0);
s4 = dome.state('water', 'p', 70, 'bar', 's', s3.s);
With no stray heat transfer in the turbine and the pump, and negligible changes in kinetic and potential energy, the steady-flow energy balance on each component gives its work or heat transfer per unit of mass flowing as a difference of enthalpies:
Wt_per_m = s1.h - s2.h; % kJ/kg
Wp_per_m = s4.h - s3.h; % kJ/kg
Qin_per_m = s1.h - s4.h; % kJ/kg
eta = (Wt_per_m - Wp_per_m) / Qin_per_m
eta = 0.3632
x2 = s2.x
x2 = 0.8251
dome.plot draws the states and the processes between them with the saturation dome. Between two states comes the property held constant: 's' for the turbine and the pump, 'p' for the boiler and the condenser.
The pump raises the temperature of the liquid by less than half a kelvin, so states 3 and 4 nearly coincide. dome.plot returns the handles of what it drew; out.labels(3) is the label of state 3, moved here below its point.
figure
out = dome.plot('Ts', s1, 's', s2, 'p', s3, 's', s4, 'p', s1);
set(out.labels(3), 'VerticalAlignment', 'top')

Updates

The toolbox is released with the Dome app. Once a day, at the first use of the toolbox in a MATLAB session, it checks for a newer release and prints one line when there is one. The commands below are listed here rather than run, because dome.update installs a new version and dome.update('off') changes a setting.
  • dome.update downloads the newest release and installs it in place of this one.
  • dome.update('off') stops the daily check, and dome.update('on') starts it again.
  • dome.version prints the version installed; with an output, it returns the version as text.
installed = dome.version
installed = '0.1.1'

Scripts exported from the Dome app

In the Dome app, Publish with the format MATLAB script writes a sheet as a MATLAB script. With "States from the Dome MATLAB toolbox" on (the default), each state in the script is a call to dome.state, so changing an input and running the script again recomputes the states. An exported script works in SI base units (Pa, K, m³/kg, J/kg, J/(kg·K)) through the option 'units', 'base'. A state in an exported script has this form:
p_1 = 1.5e6; % Pa
T_1 = 553.15; % K
state_1 = dome.state('water', 'p', p_1, 'T', T_1, 'units', 'base');
h_1 = state_1.h % J/kg
h_1 = 2.9934e+06
An exported script stops with the message "This script needs the Dome MATLAB toolbox (Dome.mltbx)" when the toolbox is not installed. With "States from the Dome MATLAB toolbox" off, the script holds the numbers Dome computed and runs without the toolbox.
